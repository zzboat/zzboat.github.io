# Chuhan Zhang — Personal Website

An English-language personal website for GitHub Pages. It uses plain HTML and CSS, with no package installation or build step.

## Site structure

The profile is followed by five sections: education, work experience, honors, research interests, and contact. The GitHub profile appears once in the navigation.

## Design palette

| Role | Color |
| --- | --- |
| Deep navy | `#10161C` |
| Graphite surface | `#182129` |
| Warm white | `#E8E5DD` |
| Muted brass | `#B69B68` |

The visual direction uses restrained typography and architectural line work over a dark navy and graphite base with muted brass accents. See [REFERENCES.md](REFERENCES.md) for portfolio templates and open-source starters reviewed during design.

## Publish with GitHub Pages

1. Create a repository named `zzboat.github.io` under the `zzboat` account.
2. Add the website files to the repository root and push them to the `main` branch.
3. In **Settings → Pages**, publish from the `main` branch and root folder.
4. After deployment, the site will be available at `https://zzboat.github.io/`.

See GitHub’s [Pages quickstart](https://docs.github.com/en/pages/quickstart) for current setup instructions. GitHub Pages sites are public by default, so publish only information you want to share publicly.
