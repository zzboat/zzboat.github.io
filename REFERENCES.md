# Design references

These public projects were reviewed for portfolio structure, visual hierarchy, content organization, and static-site publishing workflows. The site in this folder is an original, dependency-free implementation; it does not copy their source code.

## Personal portfolio examples

- [Brittany Chiang — v4](https://github.com/bchiang7/v4): a polished developer portfolio with a clear introduction, navigation, and carefully ordered content sections. Its README requests attribution when reusing the project; no source from it is reused here.
- [Astrofy](https://github.com/manuelernestog/astrofy): an Astro and Tailwind starter covering common portfolio needs such as a profile, projects, blog, and CV. Its breadth informed the initial content-architecture review.
- [Spotlite](https://github.com/hellotham/spotlite): an Astro portfolio and CV starter with Markdown-driven content and a GitHub Pages publishing workflow.

## Publishing reference

- [GitHub Pages quickstart](https://docs.github.com/en/pages/quickstart): official instructions for publishing a site from a GitHub repository.

## Design choices applied here

- A dark navy and graphite palette with restrained brass accents.
- A short, section-based profile focused on biography, education, research interests, and contact details.
- Static HTML and CSS so the site can be hosted directly from a GitHub Pages repository.
